# 《那个选择》· 有招短片制作包 v1

Issue #39 · production_pack@1 · 40 秒 / 16:9 / 目标 1920×1080 / 时间基准 30fps。

**当前是前期制作包，尚未完成动态试拍或成片。** 图片关键帧只能说明美术与取景，不能证明表演、运动、剪辑或声音已经实现。此包不是新的 VideoProjectIR，也没有注册到正式视频引擎。

## 创意

一个做过项目的工程师，排练时能流畅讲出团队成果，却答不出一个具体选择的理由。她把机械答案停下来，回看项目笔记，找回问题、选择和验证过程。结尾回到同一个问题：她开始讲自己的判断，而非再背一遍介绍。

开场的问题：“当时，为什么没选另一个方案？”观众会想知道她究竟选了什么。轻微幽默来自她听出自己那句“因为大家都这么做”的空泛后，笑着叫停自己。没有夸张崩溃、逆袭录用或虚构客户背书。

虚构练习案例：团队知识库的前端列表。文档增多后，一次加载所有内容与分批加载之间如何选择；角色先测量，再调整。**这是角色的虚构项目经历，不是有招的功能、性能或客户案例。** 不填造毫秒、提升比例或测试结果。

有招的角色：提供一个真实可见的项目资料与备注整理位置。本片可展示“项目库”和“可记录项目范围或复习备注”的实际输入/保存。AI 分析、AI 生成答案、面试录用不在本次已经实测的证据范围内。

## 观众、角色与美术

- 观众：有项目经历，却容易把面试讲成团队功能清单的求职者。
- 主角：原创虚构的 27 岁女性工程师，黑色齐下颌短发，炭灰针织外套、米白 T 恤；说话自然，有犹豫、有自我修正，不扮演播音员。表演与肖像均需标明生成来源。
- 场景：居家工作角，橡木桌、奶油色方格纸、黑色自动铅笔、酒红杯、绿色台灯；窗侧冷光、台灯暖光。前景/人物/窗景形成层次，不以灰色无缝背景承载全部画面。
- 连续性：窗在镜头左侧、台灯在右侧；笔用右手。轴线、发型、服装、道具、屏幕朝向在镜头间一致。品牌主色仅用于后期说明与真实界面，不给整个场景涂蓝。

## 动效与声音必须承担什么

动效仅承担两件事：解释“一次全加载/分批”的差别，把笔记、真实备注与人物的思考接起来。动画中的记录只是示意；不以虚构界面、虚构性能曲线或装饰线带承诺产品效果。后期图层、字幕、真实录屏可以独立修改；生成的人物画面不能承诺逐像素可编辑。

镜头运动只在注意力发生转移时使用。S01/S02 的表演靠反应和构图，S06/S08 靠实际操作与必要特写，S10 的轻推进对应她开始表达判断。避免每镜都缩放、全片恒速漂移、无缘由旋转和用转场掩盖素材短缺。

声音分为人物对白、排练搭档、房间底噪、笔与键盘动作、音乐五组。先剪对白和停顿，再做动作同步与音乐；保留前后镜头之间自然的声音接续。音乐在叫停时收掉，在重新回答时回到稳定节拍。现有 Qwen 只能作为候选声音，不能凭模型名称认定表演已达标；必须逐句听，检查重音、语义停顿和人物身份是否一致。

目标交付为旁白可懂、峰值无削波、字幕安全区可读的 1080p MP4，另保留独立音轨、字幕、真实 UI 来源与工程。响度、帧数、编码检查只验证技术条件，不证明视频优秀。

## 首次试拍：只做 S02

先审看 `trial-shot.json` 与实际生成的首帧，再取得同一镜头的明确报价。**用户已选择先审看单镜头与报价再生成，没有批准任何金额或批量任务。** 试拍目标 8 秒（剪入 S02 的 4.5 秒），留动作前后余量；16:9，目标 1080p。

重点看：说到一半的反应是否可信、是否像同一个人物、手与笔是否稳定、目光是否有目的、是否保留静止与呼吸、台灯/窗户方向是否一致。无明确剧情转折、明显口型错位、肢体变形或道具漂移，都不能仅靠后期花字掩盖。失败重试也要重新取得报价与确认。

## 审片问题

- 看完前 8 秒，是否想知道她做过什么选择？叫停是否像真实的人，而非教条台词？
- 看完是否能用自己的话讲出“问题 → 两种方案 → 如何选择 → 如何验证”？
- 产品是否真正提供了可见的资料整理证据？移除产品镜头后故事是否缺少关键一步？
- 去掉任一动效，是否真的损失信息？没有作用的装饰应删掉。
- 角色、环境、服装、道具、光线与眼神是否连续？无声观看能否理解动作？
- 关掉画面，是否听起来像两个人在排练，而不是一段被平均分割的播音文案？
- 有没有把虚构项目、生成演员、真实产品界面或实际功能证据混淆？

这些问题需要人观看和判断，不设置“AI 自评高分即通过”。
