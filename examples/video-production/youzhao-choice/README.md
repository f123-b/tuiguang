## 本机重现边界

`tools/` 保存本次实际采集/封装脚本。它们是本机制作资料，不是正式服务端 Provider；只适用于已由操作者启动的隔离有招实例。默认 CDP 为 127.0.0.1:9349，产品源码/依赖路径为 `D:/电脑面试`，输出为本仓 `.data/有招剧情制作-20261108`。不能把端口改成真实用户实例。既有目录含证据，重拍应先使用新的目录与隔离副本，不能覆盖原采集。

依赖为已有 Node 22、产品的 `ws`、Python/Pillow 和本机 FFmpeg；本轮没有新增安装、开启云付费资源或修改产品源码。实际执行的是相同内容的 `.data/capture_choice.cjs` 与 `.data/finish_choice_pickup.py`；封装脚本后续只做代码格式化。技术检查不授予质量确认或发布许可。
