# AI 持续创作者 · 全量 UI / UX 设计规范

**版本** V2.1 · 2026-11-05  
**产品原则**：Mac/iOS 质感、克制、信息清晰；持续运行可见；真正可编辑；**绝不出现 AI 自动发帖交互**。  
**包含**：完整路由地图、32 个页面/弹窗设计、设计 Tokens、交互与状态、桌面/移动适配、无障碍、前端组件契约、验收检查表。  
**浏览器可交互原型**：`../prototype/index.html`；原型使用明确标注的示例数据，不调用真实服务。

## 1. 核心体验叙事

用户登录以后看到的是一个“长期在工作中的 AI 创作者工作台”，而不是聊天机器人首页。默认首页清楚显示：今天正在创作什么、已经完成什么、哪些内容**等待我手动发布**、成长报告说明了什么、系统有没有预算/素材/审核异常。

全系统主要动作遵循：
`看计划 → 改计划 → 看成品 → 审核 → 下载/复制 → 自己打开官方平台发布 → 回来登记 → 导入指标 → 看复盘`。

发布页禁止误导按钮：“自动发布”“立即代发”“授权后无人值守发布”“已发布（脚本）”均不得出现。替代按钮是“**准备发布包**”“**下载素材包**”“**复制文案**”“**查看发布步骤**”“**我已手动发布**”。

## 2. 设计系统与视觉规范

### 2.1 气质
- 默认深色：冷静的石墨蓝背景、暖白正文、青蓝/紫的少量品牌点缀；轻透玻璃只用于顶栏、悬浮助手等小面积表面。
- 浅色：米白近中性色，低对比阴影，不大面积高饱和渐变。
- 画面以 UI 截图、真实 CG 渲染结果为主，不使用不相关的真人照片填充页面。
- 动画遵循功能性，状态变化 150–220ms，重要展开 240–320ms；支持 `prefers-reduced-motion`。

间距体系 `4/8/12/16/20/24/32/40`。顶栏 64px，左导航 248px，可收起 72px；内容最大宽度 1500px；标准卡片间距 16px；内容页边距 28px，屏宽 1200 以下 18px。

### 2.3 全局骨架

**桌面 1440+**：侧栏 248px（Logo、工作区、十个主导航、帮助与账号）+ 顶栏（面包屑、当前创作者、搜索、全局“新建内容”、通知、头像）+ 内容区。详情以抽屉提供，避免所有操作都新开页面。

**中尺寸 768–1199**：侧栏图标缩起 72px，详情按需覆盖，卡片从 4 列改 2 列，视频专业工作台自动隐藏右侧属性栏。

**手机 375–767**：底部 5 Tab（总览、日历、创作、发布、我的），二级功能通过完整页面/抽屉打开；表格转换为卡片列表；视频时间线可横向滑动，只提供镜头级轻编辑；高级时间线操作提示“前往桌面端”。

**小尺寸**：绝不将“我已手动发布”按钮压缩成语义不明的图标；按钮可换行；底部操作固定栏不得遮挡输入和列表。

| 31 | `/brand` | 品牌与事实库 | 产品/受众/价格/功能版本/出处/禁用声明 | AI 不得自动修改已锁定事实 |

## 4. 六个重点页面详细画布规范

### 4.1 总览 `/dashboard`

**布局**：左标题“今天的创作进度”，右上日期+创作者状态胶囊。第一屏 4 个统计卡：“今天内容任务”“待手动发布”“本周已登记作品”“本月创作费用”。第二屏左 8/12 “今日 AI 流程”，右 4/12 “人工待办”；第三屏左“最近成品”右“成长洞察”；底部“过去七天运营日历”。

**首要按钮**：“查看今日成品”“暂停创作者”。如待人工发布内容有 2 条，显示两张实际作品卡和“下载发布包”。

**内容缺失**：创建初始资料缺失时提供“添加真实软件截图”；没有导入数据时显示“尚未导入平台数据”，不画假趋势图。

### 4.2 AI 创作者 `/creator`

人设卡显示：名字、品牌、目标受众、栏目方向、内容风格、时区、下一次日更时间、预算。状态 Active/Paused 应具备明确文本和图标。展示“记忆样本”“本周会写什么”“最近一次修改策略”。

用户修改频率后展示“每日 09:00 → 每周二、四、六 10:00”变化预览；锁定字段修改需用户二次确认。支持“跳过明日”“暂停一周”“恢复”并清楚说明**只是停止制作任务，不影响用户已经发布的内容**。

### 4.3 宣传视频主编辑器 `/studio/video/:id`

**桌面专业布局**：
- 顶部：返回内容库、项目名称、保存状态、比例与分辨率、撤销/重做、预览、渲染、下载。
- 左栏 240px：Storyboard 6–10 个镜头缩略卡、拖拽排序、添加镜头、警告点。
- 中央区域：黑色舞台、画面安全区、画面/视频预览、播放/暂停、标尺、缩放到适应。
- 右栏 290px：镜头 Provider、动画/剪辑参数、摄像机、入场/退场时长、字体、透明度、音轨、来源证据。
- 底部约 160px：Video、Graphics、Subtitles、SFX、BGM、Voice、Reference 轨道；横向滚动。

**局部修改**：用户输入“第三镜头从右边进入，蓝色粒子少一点”，在右侧生成改动预览、影响列表、预算提示；确认后仅重渲染受影响镜头。没有预览资源时显示线框占位，但不能冒充实际成片。

**用户权限**：可编辑镜头标题，但若修改成无法证实的功能描述，系统将合规状态退回 `needs_revision`。

### 4.4 人工发布中心 `/publish`

**核心设计差异**：页面不显示“账号连接/授权发布”，改为“选择目标平台的发布规格”。

顶部说明固定显眼但不刺眼：“此处准备发布资料。AI 不会登录或替你发布到第三方平台。”

内容卡的主要按钮是“查看发布包”，次级“下载资料”“复制文案”。详情展开后按流程显示：① 复核内容 ② 下载素材 ③ 打开官方平台并由你上传 ④ 选择必要的 AI 内容声明 ⑤ 返回登记已发布。右边保留发布检查表（默认需用户勾选后才可点击“我已手动发布”，但不影响下载素材）。

登记成功文本：**“已保存你的发布记录（用户自行登记，未经平台验证）。”** 禁止 toast “平台发布成功”。

### 4.5 数据导入 `/analytics/import`

向导三步：上传文件或手填 → 选择平台及字段映射 → 检查数据来源/时间窗并确认入库。支持模板下载、重复记录检测、负数和日期异常提示。字段未映射时用户不能直接导入；导入后在数据看板始终展示来源 `用户手工` 或 `用户上传的官方导出报表`。

### 4.6 成长报告 `/growth`

顶部本周总结：“观察到的事实 / 尚不能确定 / 下周拟实验”。主体使用三个分区：① 证据卡（作品和统计快照）② 策略建议（理由、影响范围）③ 版本变化（之前→建议→接受/拒绝）。用户可锁定核心栏目比例，不让 Agent 突然改变账号人设。

## 6. 关键提示语与禁止文案

**推荐**：
- “AI 已生成今天的草稿，等待你审核。”
- “发布资料已准备好，请在平台官方客户端自行上传并发布。”
- “已保存你的手动发布记录，尚未由平台验证。”
- “这项数据来自你上传的报表。”
- “已完成内容合规预审；平台最终审核结果以官方为准。”
- “AI 已提出新的选题建议，请查看依据。”

**禁止**：
- “全自动代发”“无视风控”“保证零封号”“平台发布成功（无回执）”“已通过官方审核（仅内部预审）”“今天涨粉 XX（无数据）”“连接社媒账号解锁全自动”。

全局帮助侧抽屉支持目录、搜索、当前页面说明、常见问题。每个关键页面的 `?` 链接到 `03_用户使用手册.md` 的对应段落，具体映射：
- 新建创作者 → 手册 §3；
- 日历和持续任务 → §4；
- 图文 → §5；
- 宣传视频 → §6；
- 人工发布 → §7；
- 数据导入 → §8；
- 成长与学习 → §9；
- 账号安全与 AI 声明 → §10；
- 故障与恢复 → §12。

帮助内容使用用户语言而非 API 语言；高级工具知识可以折叠显示。

## 8. 无障碍与响应式验收

- 375、390、768、1024、1440、1920 画布验证；主操作无溢出、无误截断。
- 所有表单具 label、错误提示、Enter/Space 可操作、ESC 可关闭弹窗。
- 图表有文字摘要和单位；状态色配合图标和文字。
- 预览播放时可暂停动画，默认尊重 Reduced Motion。
- 文件上传说明支持格式/最大体积/隐私条件，加载或失败有明确提示。
- 中文长标题和真实多平台标签不可遮挡按钮。
- 触控目标建议至少 40×40px，桌面高密度控件允许适度减小但保持可点击性。

## 9. 完成度验收

1. 每个页面拥有可访问路由、真实数据契约、加载/空/错误状态及帮助文案。
2. 不同屏幕的导航、按钮、状态颜色和术语一致。
3. 用户能在 5 次操作内从“今日待发布”进入资料下载与手动发布指引。
4. 手机端能检查草稿、下载包、登记发布、导入少量指标；专业视频时间线以桌面为主。
5. 所有使用“发布”一词的 UI 经过人工发布边界文本审计。
6. UI 原型可以用示例数据展示交互，但正式产品不得将示例作品、浏览量或模型回复标记成真实服务结果。

## 11. V2.1：全类型宣传视频工作室新增完整 UI 设计

**主导航**：“AI 宣传视频”取代“CG 视频工作室”。保留原视频工作台和分镜页，但不再暗示视频只使用软件真实截图或三维界面。

### 11.1 新建宣传视频页（7 个模式）

- **AI 智能推荐（默认）**：输入宣传目标、受众、品牌产品、视频用途和预算，由 DirectorAgent 返回方案 A/B/C，展示每个方案的风格、预计时长、成本与风险。
- **2D/MG 图形动画**：动态字体、插画图解、科技信息图。
- **3D/CG 动画**：三维产品、样机、镜头动画。
- **卡通故事动画**：故事板、角色/背景一致性。
- **软件录屏演示**：真实软件界面、光标、高亮、自动剪辑。
- **AI 创意镜头**：文/图生视频、转场与背景视效。
- **素材混剪**：用户素材/合法图库 + 配音 + 字幕 + 音乐；还可选“混合制作”。

表单含：`营销目标`, `目标受众`, `核心卖点`, `品牌事实版本`, `视频模式`, `整片视觉主题`, `参考风格`, `时长`, `比例`, `配音方式`, `字幕`, `预算`, `版权确认`, `隐私授权`。

### 11.2 全类型分镜编辑器

左侧镜头列表显示镜头类型小图标、制作 Provider、长度、缓存状态与渲染状态。中央画布/播放器切换“单镜头预览/全片预览/音频波形”。右侧检查器可对**当前镜头**选择 Motion Canvas、OpenFilm、ComfyUI/Wan、Blender 等引擎，并显示设备需求、版权条件、费用预估和可否局部修改。底部多轨道支持视频、图形、字幕、旁白、音效、BGM、参考图层。

状态：`未选择引擎`、`等待审核`、`生成中`、`生成成功`、`输出不可编辑图层`、`需付费 API`、`需要 GPU`、`素材待授权`、`质量异常`、`待用户手动发布`。

### 11.3 视频项目与模板页

增加“**视频模板与项目工程**”，区分“内容模板（功能教程/品牌形象/问题解答）”和“风格模板（极简/MG/3D/卡通/科幻）”。视频不应因创作模式变化被覆盖，保留工程格式、引用素材和镜头版本。

### 11.4 每日持续创作页面

内容日历可以直接显示当日将制作“图文、录屏教程、MG 动画、卡通故事、混合广告”的规划，Agent 根据栏目、历史表现和预算自动分配形式；用户可锁定本周风格或调整创作类型。全类型宣传视频仍需经过审查、**人工下载和本人发布**。

### 11.5 表单交互与原型边界

离线原型中选择视频模式、场景引擎是可点击的**配置演示**，不代表已安装或运行任何本地生成模型；不得出现虚假 MP4 文件链接。视觉预览是 CSS 示意，未来由真实服务接管。移动端只做模式选择、分镜预览、关键文案编辑；多轨时间线主要留在桌面端。
