# AI 持续创作者 · 用户使用手册

**用户版 V2.1 · 2026-11-05**  
适用于：网页端及桌面端（正式产品按功能分阶段上线）。本文描述的是**拟开发产品的完整操作规范**；交互原型可供体验，但其中的创作任务、成片和数据为示例，不能代表后台能力已经上线。

---

## 使用前先了解三件事

**第一：AI 会一直为你准备内容，但不会替你向平台发帖。** 你可以让软件每天自动策划、写文案、做封面或 宣传片，它会在“人工发布中心”放好素材和文案。你需要在小红书、抖音等**官方应用或官网**亲自上传并点击发布。

**第二：你不用把社媒账号密码交给本软件。** 软件记录的是创作目标、平台内容格式、你自己填写的作品链接及手工导入的运营数据，不会要求你提供 Cookie、短信验证码或登录态。

**第三：AI 的预审不是平台批准。** 即使本软件提示“内容预审通过”，也要按你实际使用的平台最新规则检查内容、广告标识和 AI 生成声明。手动发布能减少自动化操作风险，但不能保证不会被限制或处罚。

## 2. 新用户 10 分钟上手

### 步骤 1：创建品牌
打开**品牌与素材 → 新建品牌**。填入软件名称、产品介绍、官网（可选）、目标用户、主要功能。建议上传：Logo 1 张、真实截图 3–6 张、真实操作录屏 1 段（可选）。

> 建议用能证明功能存在的界面和说明文档。AI 不会自动相信一句“世界第一”“保证拿 Offer”之类无法证明的宣传语。

### 步骤 2：创建 AI 创作者
打开**我的创作者 → 新建创作者**。选择创作风格（如“理性科技风”）、主要平台（仅用于适配内容尺寸与风格）、计划频率（如每天一篇、每周两条 宣传视频）以及每日预算。设置所在时区和“需要提醒我的时间”。

### 步骤 3：预览计划
检查 AI 提议的未来 7–14 天选题。可以点“改选题”“换栏目”“跳过这天”。确认之后启用创作者。

### 步骤 4：查看第一条内容
进入**今日任务 → 查看成品**。如果是图文，检查文案、封面与功能描述；如果是 宣传视频，播放检查各个镜头的真实界面、字幕和声音。

### 步骤 5：下载并自行发布
进入**人工发布中心 → 发布包详情**。下载 MP4/图片/封面，复制标题和正文，在平台官方客户端上传并发布。完成后返回软件点**“我已手动发布”**，记录平台作品链接（可暂时留空）。

### 步骤 6：导入效果数据
过一段时间，从平台官方后台查看数据，选择**数据与成长 → 导入数据**，上传报表或手动填写。等数据积累后查看周报和新选题建议。

## 3. 创建和管理 AI 创作者

### 3.1 创建创作者
在“我的创作者”点击“新建”，按表单填写：

| 项目 | 示例 | 是否必须 |
|---|---|---|
| 创作者名称 | 有招产品内容官 | 是 |
| 品牌 | 有招 | 是 |
| 定位 | 面试练习与软件使用技巧分享 | 是 |
| 目标用户 | 求职学生、技术岗位候选人 | 建议 |
| 主要内容栏目 | 面试技巧、功能教程、动画/混剪等宣传视频 | 是 |
| 更新频率 | 每天 1 篇图文，每周 2 条视频 | 是 |
| 时区 | Asia/Shanghai | 是 |
| 日/月费用上限 | 根据预算设置 | 是 |
| 语言及语气 | 简洁、可信、不夸张 | 建议 |
| 禁用说法 | “100% 面试成功” | 建议 |

平台选择仅决定生成内容时的比例、封面、文字风格和清单，不会尝试登录平台。保存后可随时修改。

### 3.2 暂停、恢复和跳过一天
在创作者详情点“暂停创作者”，后台不再开始新的创作任务。已完成的草稿不会删除，已在平台手动发布的作品当然也不会被撤回。

“恢复”会按当前预算与素材状态继续安排未来内容。“跳过今日”只对本日计划生效，不等于永久暂停。

### 3.3 纠正 AI 的长期认知
如果 AI 错误地认为软件支持某个功能，请到**品牌与素材 → 产品事实**修正并锁定；如果只是写作风格不喜欢，到**成长与记忆 → 创作偏好**调整。系统应保留旧版本的来源记录以便排查。

## 4. 设置日更计划与运营日历

### 4.1 制定栏目
在“选题与日历”选择：使用教程、场景痛点、产品更新、常见问题、软件设计故事、CG 宣传展示。为每类栏目设置优先级或给 AI 一个“本周重点”。

### 4.2 调整未来计划
切换“周视图/月视图”，打开某一天的内容卡，可以编辑标题、锁定该主题、改期、跳过，或要求 AI 给出另一个角度。

### 4.3 日更没有完成怎么办？
先查看“通知”里的失败原因：可能是素材不足、审核未过、渲染失败或费用已到上限。软件不会为了完成日更任务而自动发表低质量内容。可以修复后继续执行，或者跳过当日。

### 4.4 能否一次生成一周内容？
可以使用“批量准备未来内容”。这只是提前创建草稿和可下载发布包，不会批量向平台提交。批量生成前会显示估算费用与预计数量。

## 5. 制作图文和封面

1. 进入**内容工作室**，打开今日选题或点“新建图文”。
2. 选择目标平台的内容规格，如竖版封面和建议标题长度。
3. 在左侧确认使用真实软件截图、Logo 或授权插画。
4. 中央预览封面、图文卡片；右边编辑标题、正文、标签。
5. 点击“检查事实与合规”，查看被标注的夸张承诺、来源不明图片或 AI 声明风险。
6. 审核无误后点“准备发布包”。
7. 进入人工发布中心下载图片/复制文案。

**平台版本是不同文案**：不建议将一篇内容不改动地复制到所有平台，AI 可以调整长度和表达方式，但不能改写产品事实。

**改稿示例**：你可以输入“把标题写得更具体，不要像广告”“保留这个功能点，删掉未经证实的优势”。

## 6. 制作软件宣传视频

![宣传视频工作台界面演示（不含真实渲染文件）](../prototype/video_editor_preview.png)

*图 2：宣传视频分镜、舞台预览和镜头属性的界面原型。*


### 6.1 适用范围与类型

**宣传视频不限于 CG 动画。** 支持 2D/MG 动图、3D/CG、卡通/插画故事、真实软件录屏、素材混剪、AI 生成创意镜头及混合式短片。你可以让 AI 根据宣传目标自动选择，或者自己指定。真实产品功能演示必须来自可靠的实际录屏/截图；抽象创意片段可使用其他获授权的素材。

### 6.2 创建视频
1. 进入**AI 宣传视频工作室 → 新建视频**。
2. 设定宣传目标（软件介绍、教程或品牌形象）、真实功能卖点、受众与预算。
3. 选择**AI 智能推荐**，也可指定 **2D/MG、3D/CG、卡通、录屏、AI 创意、素材混剪、混合制作**。
4. 选择 `15/30/60 秒` 和 `9:16/16:9/1:1`，上传/引用经授权的素材；有真实功能演示时必须附真实操作素材。
5. 选择配音方式、字幕和背景音乐，再点击“生成分镜”。
6. 在分镜编辑器查看每个镜头的**制作引擎、素材、字幕、时长、成本和许可状态**；允许逐镜头换引擎。
7. 预览和确认方案后进行真正渲染，导出时保留可编辑工程。

### 6.3 修改某一个镜头

打开视频编辑器，可以把镜头 3 从“录屏演示”改为“MG 图形解说”，或在不影响实际产品事实的前提下将某个动画镜头改成卡通风格。修改后先检查版权、模型提供商费用和可能的合规标识，再仅重做受影响的镜头。

### 6.4 导出什么？

一个标准视频发布包包括：`主视频.mp4`、`封面.png`、`标题与简介.txt`、`话题标签.txt`、`AI生成内容与素材说明.txt`、`发布检查表.md`；用户可选下载 `.zip` 和工程项目文件。

### 6.5 注意事项

生成式视频和用户上传素材都应检查权利来源。真实软件操作不得由 AI 虚构 UI、虚构性能或冒充真实用户评价。人工发布前仍需核查平台当时适用的营销规则与 AI 内容声明要求。

## 7. 在平台上自行手动发布

![人工发布资料包界面演示（所有上传与发布均由用户在官方平台完成）](../prototype/manual_publish_preview.png)

*图 3：人工发布资料包，包含预览、检查表、文案复制和手动发布登记入口。*


### 7.1 发布前 5 项检查
在**人工发布中心 → 发布包**查看：

- [ ] 我确认软件功能、价格、用途与视频演示真实。
- [ ] 我确认图片、录屏、配音、音乐等素材拥有适当使用权。
- [ ] 我已经阅读目标平台当前适用的内容规范，必要时选择营销/广告声明。
- [ ] 对 AI 生成或合成内容，已按法律及平台要求准备声明或标识。
- [ ] 我愿意在平台官方客户端/官网自行操作发布。

### 7.2 下载素材与复制文案
点“下载发布包”，可得到视频/图片、封面、文字文件和声明检查单；也可以分别点击“复制标题”“复制正文”“复制话题”。软件可以打开平台公开的官方网站，但不会替你上传或操作发布按钮。

### 7.3 打开官方平台发布
由你手动打开抖音、小红书、闲鱼等应用或其官方创作者入口，根据页面提示自行上传、填写信息并发布。平台 UI 经常变化，软件内步骤只能作参考；遇到平台要求认证、审核或标签声明时，以官方最新提示为准。

### 7.4 回来登记已发布
发布后回到本软件，打开对应内容，点击**“我已手动发布”**，填入发布的平台、日期时间、作品链接（可留空）和备注。系统显示：

> 已记录你的发布情况。该状态由你自行登记，尚未经第三方平台验证。

如果没有发布成功，选择“未发布/继续等待”，不要为了获得分析报表而登记成功。后续如记录有误，可纠正或撤销。

### 7.5 每天没有时间发布怎么办？
允许先保留草稿，选择“每天汇总提醒”或者“每周集中下载”。AI 仍按计划创作；系统不会在你未操作时擅自把内容发布出去。

## 8. 导入真实数据

### 8.1 手动输入
进入**数据与成长 → 导入数据 → 手动录入**，选择对应作品和平台，填写指标（如播放/阅读/收藏/评论/咨询），同时填写统计时间窗和你读取数字的日期。没有看到的指标留空，不能填 0 充数。

### 8.2 上传官方报表
从平台官方创作者后台导出可用的报表。进入“导入数据”选择文件，软件显示字段映射与预览，确认单位、日期和作品映射后入库。如果官方报表结构不同，请手动映射列，不要猜含义。

### 8.3 为什么看不到自动获取的播放量？
因为本版本不会登录或抓取第三方社媒后台。平台数据来自你主动提供的资料。没有数据时，“数据与成长”会显示**尚未导入**，而不是虚构增长曲线。

### 8.4 重复导入怎么办？
系统需要根据平台、作品、指标、统计窗口与来源批次提示重复，并允许覆盖更晚的真实统计快照；保留修改记录。

## 9. 查看 AI 成长报告

进入**数据与成长 → 成长报告**，可以看到：

**事实部分**：哪些作品有真实数据，哪些观察窗口可以比较；  
**推测部分**：某类教程可能更容易得到收藏，CG 片可能更适合提高品牌辨识；  
**行动部分**：下周优先做什么、减少什么、还需要试验什么。

如果 AI 认为某个栏目应从每周 1 次调整到每周 3 次，会给出证据、对比和建议；你可**同意 / 暂不采用 / 锁定该栏目比例**。用户可以删除不正确的偏好记忆或回滚策略。

**重要**：浏览多、咨询多、注册多代表不同目标，不应混成一个“综合成功率”。AI 不能宣称平台算法偏好某种内容，除非有充分证据，仍应作为假设表达。

## 10. 账号安全、真实宣传与 AI 标识

- 软件不需要你的社交平台登录凭据，任何要求输入平台密码的陌生页面都应谨慎对待。
- 不做模拟人工点击发布、批量私信或刷互动；发布由你自己完成。
- 人工发布**不能保证不封号**：违规广告、侵权、虚构经历、生成合成内容未按要求标识等仍可能带来风险。
- 对产品功能、性能和用户评价的陈述需有证据；不得伪造使用体验。
- AI 参与制作宣传视频、配音或合成画面的部分，请按照适用法律及平台规则进行声明或标识。
- 官方平台的规定可能变化；发布前请检查当时的实际要求。软件“预审通过”只代表内部检查，不代表平台审批。

## 11. 模型、预算与通知设置

### 11.1 模型配置
设置 → 模型服务，可使用平台提供的模型或用户自带 Key。使用第三方模型时，上传的商业资料可能按该模型供应商的条款进行处理；请仅上传已获授权可处理的内容。

### 11.2 预算
设置 → 成本与额度，分别指定每日总预算、月度总预算和高成本视频生成上限。超限时创作任务暂停，系统不会自行购买额度或提升预算。

### 11.3 通知
设置 → 通知，可选择每日创作完成、待发布、渲染失败、内容审核问题、每周复盘及费用警报。可设置免打扰时段。

## 12. 常见故障与处理

| 遇到的问题 | 可能原因 | 处理办法 |
|---|---|---|
| 今天没有生成内容 | 创作者暂停、错过任务、预算不足 | 查看运行日志，恢复或重新运行；确认时区 |
| 宣传视频一直渲染 | 镜头错误、素材缺失、队列积压 | 查看渲染任务详情，修正素材或重试失败镜头 |
| AI 说错软件功能 | 品牌事实不完整或过期 | 到品牌中心修改、添加真实证据并重新生成 |
| 合规审核无法通过 | 夸大表达、版权、素材或 AI 标识问题 | 看被标记区段，修改后重新审查 |
| 发布中心找不到“自动发布” | 产品刻意不提供此功能 | 下载资料，自己到平台官方界面发布 |
| 已经发布却显示待发布 | 尚未登记 | 进入作品详情点击“我已手动发布” |
| 手动填写链接报错 | 格式无效或不是所选平台 | 检查 URL，暂时不填也可登记 |
| 数据看板显示无数据 | 尚未导入真实数据 | 从官方后台导出报表或手动输入 |
| AI 复盘看起来没根据 | 数据量少/不可比/缺少来源 | 查看证据卡；拒绝不合理策略并继续采样 |
| 费用突然增多 | 高级 CG、重渲染、模型成本 | 在任务用量中查看明细并降低额度上限 |
| 上传素材无法识别 | 文件格式、体积、损坏 | 用常见 PNG/JPG/MP4 重试，检查尺寸 |
| 无法恢复创作者 | 仍存在待处理错误、预算或缺失素材 | 点击“查看阻断原因”，修复后再恢复 |

## 13. 术语解释与常见问题

**AI 创作者**：一个持续运作的账号内容策划/制作实体，不是第三方平台账号。  
**内容包**：某一选题的文案、封面、图片/视频及合规信息的组合。  
**人工发布包**：准备给你自己去平台上传的文件与复制文案。  
**宣传视频**：通过程序化图形与软件真实 UI 制作的动画宣传片。  
**日更任务**：AI 在指定日期准备创作内容的计划。  
**用户登记已发布**：你自己告诉本软件已发布，不是官方 API 证明。  
**合规预审**：本软件的参考审核，不是平台官方裁定。  
**品牌事实库**：经用户验证的产品描述和素材依据。  
**学习报告**：AI 基于已提供的数据提出下一轮建议。

**问：能完全不操作就自动发布到小红书吗？** 不能。本版本明确不提供第三方自动发帖。  
**问：AI 还会每天做内容吗？** 会，只要创作者处于运行中且预算/素材条件满足。  
**问：可以只做图文不做视频吗？** 可以，修改内容格式与频率。  
**问：可以只用自己上传的截图，不用文生视频模型吗？** 可以，软件 宣传视频优先采用真实 UI + 程序化渲染。  
**问：不导入数据，还能继续创作吗？** 可以，但 AI 会明确说明没有效果数据、只能根据品牌目标与用户反馈优化。  
**问：能不能保证账号安全？** 不能。软件能降低第三方自动化操作风险并辅助内容审查，但平台最终认定与账号状态不受本软件控制。  
**问：HiveMtk 的客服功能在哪？** 该功能规划于后续版本；不是当前产品主流程，也不会自动发送第三方私信。

## 14. 隐私、删除与帮助

在设置 → 隐私与数据，可查看 AI 模型服务、导出个人作品、取消创作者日程、删除不再需要的素材与记忆。删除前必须提醒可能影响已关联内容项目，已手动发布到第三方平台的作品需要用户在对应平台自行管理，本软件的删除操作不会修改第三方作品。

遇到问题可通过右上角 `?` 打开当前页面帮助，查看操作步骤和排查办法。产品帮助中心应展示这份手册的网页版本，保持与正式产品功能同步更新。

## 15. 全类型宣传视频制作与每天使用（V2.1 增补）

### 15.1 我现在可以制作哪些视频？

你不需要懂 CG：可选择“AI 智能推荐、2D/MG 动画、3D/CG 动画、卡通插画、真实软件录屏讲解、AI 生成场景、素材混剪、混合制作”。不同方式可以出现在同一个视频里。正式产品的引擎可用性与资费会展示在模式选择页；离线原型只演示配置和版式。

### 15.2 首次制作一条宣传视频

1. 打开“内容创作 → AI 宣传视频”，点击“新建宣传视频”。
2. 选择想宣传的真实产品、目标人群和目标（例如软件认知、注册、产品教程）。
3. 选择“AI 智能推荐”；或者明确选“卡通/MG/软件实录/3D/混剪/AI 创意”。
4. 上传或选择可合法使用的素材；若涉及真实软件操作，请上传**实际录屏/截图**并审核功能事实。
5. 设置长度（15/30/60 秒）、比例（9:16/16:9/1:1）和预算；先预览分镜方案。
6. 在“分镜列表”中逐个选择镜头、切换制作引擎、修改文字、配音和画面；每个镜头可以不同。
7. 进行真实渲染后播放成片，检查字幕、画面事实、AI 生成标识、版权与音量。若有问题，只修改并重新生成相关镜头。
8. 审核通过后导出 MP4、封面、标题、简介、标签及素材来源清单；**由你在目标平台官方 App/网站亲自发布**。

### 15.3 AI 如何决定今天制作哪种视频？

AI 读取本周栏目和真实数据：教程类可能推荐“录屏 + MG”，品牌形象类可能推荐“AI 创意画面 + 3D 文字”，知识型内容可能推荐“卡通图解 + 配音”。成本不足时优先使用已授权素材和轻量动画。你可以为某个栏目固定风格，也可以在选题卡片里选择“本次强制使用卡通动画”。

### 15.4 合成画面和真实功能如何区分？

AI 生成的抽象/卡通场景可以作为视觉包装，但**不能冒充真实软件界面、实际用户评论或确实存在的产品功能**。你需要在发布前确认所有卖点、软件版本、价格、肖像和音乐授权，并根据平台要求使用 AI 内容标识。AI 预审不是平台官方审核。

### 15.5 常见问题

**不安装显卡也能做吗？** 可以使用云端服务、已有素材混剪和轻量 2D/MG；3D/本地视频生成可能需要额外计算资源。

**一条视频里能有多种风格吗？** 可以。进入分镜编辑器，为各镜头单独指定类型和引擎；正式版需要根据统一轨道输出。

**能完全免费生成所有视频吗？** 不能保证。开源项目代码许可不代表模型调用、GPU、音乐和素材全部免费。生成前需看到成本估计。

**能每天自动做不同风格吗？** 这是持续创作者的核心目标。系统每日根据选题、预算和真实反馈调整内容形式，但仍由你完成最终平台发布。
