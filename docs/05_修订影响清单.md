# 修订影响清单 · 从“可自动发布”统一变更为“人工发布”

本文件用于核对所有受影响模块，防止旧代码/旧界面保留隐性自动发帖入口。`01_产品完整开发方案_人工发布版.md` 为唯一有效产品基线，以此覆盖此前旧版 Markdown 中矛盾的内容。

| 旧方案区域 | 旧设计/隐患 | 最新统一设计 | 影响文件/模块 | 验收证据 |
|---|---|---|---|---|
| 项目定位 | “审批/授权发布”，存在自动发帖歧义 | AI 持续创作，用户本人最终发布 | README/PRD | 首页说明明确 |
| Agent | PublishingAgent 可以选择发帖 Connector | ManualHandoffAgent 只生成发布包和提醒 | Agent graph/tools | 不存在 publish.submit |
| 任务状态机 | submitting/platform_review/confirmed_published | awaiting_manual_publication/user_reported_published | enums/models | 无自动提交路径 |
| 平台能力 | OAuth 授权账号/自动发布 API | 平台内容规格和官方操作说明 | platform guides | 不要求社媒登录 |
| 登录凭据 | Cookie/Token/二维码登录态 | 不采集这些信息 | settings/secrets | DB 字段/页面不存在 |
| 前端“发布”按钮 | 一键发帖、任务重试 | 准备/下载/复制/查看指南/我已手动发布 | UI/routes | 所有按钮仅内部动作 |
| 浏览器助手 | 自动操作社媒发帖页 | 仅本地真实软件截图和素材选择 | Tauri | 外部页面不会自动上传 |
| 发布回执 | 脚本成功推断已发布 | 用户手动登记来源标记 | manual_publish_records | UI 显示未官方验证 |
| 失败重试 | 自动重发存在重复风险 | 内部渲染/导出可重试；平台发布无重试工具 | worker | 无平台写请求 |
| 定时任务 | 到点自动发布 | 到点自动制作并提醒 | scheduler | 只生成内容任务 |
| 数据自动抓取 | 隐含后台监测、数据读取 | 用户提供 CSV/XLSX 或手填指标 | analytics/import | 缺数据不虚构 |
| 周复盘 | 使用“真实平台数据”但未说明来源 | 保留来源、时间窗、置信度 | learning engine | 支持数据溯源 |
| 合规引擎 | 自动发布前的 API 权限审核 | AI 内容预审+人工作品发布检查清单 | compliance | “预审≠官方审核” |
| AI 标识 | 模糊声明 | 视频/图文标识检查和提醒，用户在官方界面选声明 | media/handbook | 发布包有检查表 |
| 客服/CRM | HiveMtk 私信桥接可能自动回复 | V2 仅授权/人工输入和回复建议，不自动私信 | support/crm | 禁用第三方自动发送 |
| 开源插件 | social-auto-upload、xiaohongshu-mcp | 不作为 V1 运行依赖；只作为历史研究，不嵌入产品 | dependencies | 依赖扫描不出现 |
| 文案营销 | “365 天全自动运营账号” | “持续自动创作，用户自行发布” | website/pricing | 外部宣传一致 |
| API | `/publishing/tasks`, `publish/verify` 不清晰 | `/manual-publication/packages/records` 明确语义 | OpenAPI | API 无社媒发帖能力 |
| 预算 | 自动平台操作成本不透明 | 模型/CG/存储成本，用户预算上限 | billing | 账单来源可查 |
| UI 原型 | 只有若干概念页面 | 32 个页面完整设计规范+可点击离线主流程 | UI/spec/prototype | 可交互原型能运行 |
| 使用手册 | 未覆盖人工发布和指标导入 | 从首次使用到成长报告全流程 | handbook | 每个核心页面能找到帮助 |
| 验收标准 | 至少一条官方接口端到端自动发布 | **绝无第三方平台自动发帖**；人为完成后登记 | tests | 网络出口/代码扫描 |
| 发布异常 | 验证码、风控自动恢复 | 软件不触碰平台发布，提示用户官方渠道自行处理 | help | 不存在绕风控动作 |

## 产品词汇统一表

| 禁止/废弃术语 | 统一术语 |
|---|---|
| 自动发布、代发、代用户发帖 | 人工发布、手动发布指引 |
| 已发布成功（没有平台回执） | 用户登记已发布（未经平台核验） |
| 平台审核通过（本地判断） | 内容合规预审通过 |
| 连接抖音/小红书账号 | 选择平台内容规格 |
| 平台自动数据同步（未获授权） | 用户导入数据、用户手填数据 |
| 养号/自动互动 | 不支持，明确禁止 |
| 发布排期任务 | 创作排期和手动发布提醒 |
| 自动回复平台私信 | AI 回复建议，由用户自己处理 |

## 代码/文档审计命令建议

```bash
# 在正式源码中查找旧的外部副作用关键词，并逐处人工审查；搜索结果不等于功能违规
rg -n -i 'auto.?publish|publish\.submit|platform.*login|cookie|browser.*post|send_dm|post_comment|playwright' apps services packages

# 在页面中查找可能误导的宣传
rg -n '自动发布|全自动发帖|保证不封号|平台发布成功|平台审核通过' apps/web

# 寻找 DB schema 与 API 中被弃用的状态
rg -n 'submitting|confirmed_published|publish_attempts|publish_receipts|platform_accounts' services packages
```

上面的 `rg` 仅为审计提示，出现关键词不等于违规；关键是**没有可执行的第三方发帖路径**。任何功能使用第三方平台登录态即使通过测试，也不应被合并进此版本。


## V2.1：宣传视频不限于 CG（2026-11-05）

- 业务命名：“CG 视频工作室”→“AI 宣传视频工作室”；CG 作为 3D/CG 子类保留。
- 视频生成：“真实 UI + 2.5D/3D”→“2D/MG、3D/CG、卡通/插画、录屏、AI 生成画面、混剪及混合式”。
- 数据模型：`style` 单选增加 `creative_direction` 与 `shots[].engine/type`；整片默认 AI 推荐，镜头可以不同。
- 架构：新增 OpenFilm 主时间线、Motion Canvas MG、MoneyPrinterTurbo 自动短视频、ComfyUI/Wan AI 片段、Blender 3D 的独立引擎适配。
- UI：新建页增加类型选择，镜头编辑器增加每镜头制作引擎、成本、版权/事实提示。
- 使用手册：新增多类型视频创建教程和 5 个常见问题。
- 合规：真实产品功能不得被模型虚构；生成式画面需 AI 标识提醒；资产授权按引擎、模型、素材分别核验。
- 发布：**完全不变**，用户下载作品后在各平台官方客户端/网站手动发布。
