# ADR 0010：软件产品片的画面导演与声音后期

Issue #31。用户明确选择真实界面、重点特写、品牌动效的软件发布片。旧成片每镜重复文字/圆圈，素材被整体缩小，缺少构图和叙事变化；原 HD MG 先按半分辨率绘制再放大，不能以 1080p 文件参数代替细节质量。

在 IR 1.1 中增加兼容的 Presentation / SceneDesign（旧调用默认 classic），新界面默认 studio。以独立 scene renderer 绘制原生输出尺寸的字形与图层，FFmpeg 执行分层错峰入场和克制转场；版式含开场、重点卡、步骤、真实界面、收尾。视频与截图只能来自已核实授权资产，取景由明确百分比裁切定义，不合成假界面。颜色、标题、标签、要点和取景可在编辑器修改，锁定保护沿用原逻辑。

声音后期按用户开启的项目设置执行旁白/配乐分组、配乐避让、淡入淡出和响度规范化；不捆绑音乐或声称系统语音具备商业播音品质。字幕采用安全边距和高对比，素材镜头避免重复烧录同一段主文案。新建产品片提供分段内容结构，用户要求入口可选择本套制作方案；原配音、版本、素材核实和预览确认仍生效。

DB 不变，新增 video_presentation@1，provider pillow_ffmpeg@4，App 0.15。新旧方案分别可读取；旧文件/审核不因引擎代码变更改写。用同源视频的旧/新帧、真实有声成片、三比例、裁切/文字/来源/缓存及旧功能回归验收。艺术质量仍需用户观看判断，不能自动宣布“符合所有专业标准”。
