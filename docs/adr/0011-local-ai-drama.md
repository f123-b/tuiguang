# ADR-0011：本地生成式镜头作为独立异步队列

- 日期：2026-11-08；任务：#45；状态：开发实施，艺术质量等待实际试片审看。
- 依据：用户要求类似 AI 短剧，真人与动漫均支持，先真人；暂不依赖 Runway、不上线。延续 ADR-0002 的 VideoProjectIR / Shot / EngineProvider 边界。

## 决策

独立本机 ComfyUI 服务执行固定原生 Wan 2.2 TI2V-5B 图生视频工作流，API 只连接显式端口的 `http://127.0.0.1`，不接收节点图、下载 URL 或第三方端点。生成不放在 HTTP 请求或主创作者 Worker 内；独立 Worker 使用同一 Qwen GPU 文件锁。成片阶段只读取已生成、校验字节且用户确认过的片段，保留生成 job、参考图、权重哈希、seed、工作流哈希及服务回执。剪辑不要求生成服务持续在线。

任务提交前先保存 `submitting` 意图，再进行一次 POST。回执不明进入 `unknown`，不自动重复生成；已有 provider_request_id 只能显式恢复读取该回执。没有回执时须检查服务日志，软件不猜测成功或重发。技术检查不等于艺术审核。输出默认未核实，必须单独确认人物、动作、内容与使用权。

## 范围与影响

- DB 新增 0015 生成任务表；旧工程的可选 generation_job_id 不存在时不序列化，IR 1.1 继续兼容。
- 真人/动漫采用同一模型，通过参考图与风格指导区分；不保证跨镜头身份一致、不提供对口型。支持49/73/97/121帧、24fps、最多901120像素；V2默认1280×704/121帧和原生解码，旧512请求兼容但明确为低清试算。用户已否决低清试片，不将技术成功当成片质量。
- 本地权重约 18.1GB，另需运行时与缓存；占用本机 GPU/RAM，无付费云端调用。
- ComfyUI GPL-3.0 独立服务不随仓库分发；Wan 权重来源和 Apache-2.0 标注单独记录，不能据此认证输入素材或成片商业使用权。
- 第三方平台最终发布仍由用户完成。本功能不新增社媒网络写入。

## 验证与回滚

契约测试验证隔离、授权、来源变化、幂等、未知提交不重发和审核门禁；实际模型样片单独存证，测试合成色彩图只证明队列/封装能力。保留升级前 SQLite 备份；回滚代码到 114d3c4 并恢复已验证备份，不执行破坏性 downgrade。
