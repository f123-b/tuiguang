# ADR 0007：创作质量报告与预览确认

状态：已实施；对应 Issue #25，0.12.0-dev / DB 0012。

质量模块提供可复查的规则依据、近 30 条标题对比和近 10 条镜头结构对比。规则只能测量长度、引用与相似度；受众价值、单一收益点及表达目的需要人工或可选模型建议，不预测流量，不自动认证事实。报告冻结品牌版本、作品版本及比较依据，历史不可改写。

模型复核单独授权发送当前作品、已核实事实和比较标题，使用现有加密配置、预算账本、一次性任务和未知费用处理；不得隐式触发付费，不自动采纳建议或审核通过。

新界面创建的工程默认启用预览政策；旧工程保持原流程。预览采用 360/640 画布、实际烧录内部预览水印，与高清文件分开记录；预览不得作为成片或进入发布包。高清提交和执行均检查当前版本、预览字节、素材授权及绑定报告的人工确认。编辑或依据变化使确认失效，硬性事实/素材阻断不能人工跳过。

新增 DB 0012：video_projects.preview_required、render_jobs.purpose、quality_reports、quality_reviews。默认值兼容旧数据。完整回退使用升级前数据库及对应资产备份，不删除审核历史。变更影响视频渲染、内容审核、可选模型费用、API、界面和私有导出，不改变人工发布边界。

真实 DeepSeek 兼容性：官方 `api.deepseek.com` 的 Flash / V4 模型默认思考。固定 JSON 创作流程显式使用 `thinking.type=disabled`，其他网关请求不加此参数；兼容适配器 `compatible_chat@2` 纳入公开配置及冻结 hash。依据：[思考参数](https://api-docs.deepseek.com/guides/thinking_mode/)、[模型与人民币报价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核验于 2026-11-06。没有保存或显示思考过程。
