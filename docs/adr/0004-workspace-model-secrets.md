# ADR-0004 工作区模型设置与密钥

状态：本地开发实施，2026-11-06。依据用户持续开发到完成的授权；无生产发布或付费调用授权。

工作区覆盖配置与全局服务端环境配置分开。普通页面只返回脱敏元数据，不返回 API Key 或密文。密钥使用 PyCA cryptography Fernet 认证加密，不自制加密算法；主密钥独立于 JWT。开发环境可在忽略的私有 `.data` 原子创建主密钥；生产必须显式配置，缺失/损坏/解密失败均拒绝，绝不回退明文。

配置 URL 必须是 HTTPS、无账号、无片段/查询；主机须在服务端 MODEL_ALLOWED_HOSTS 允许列表（默认仅 api.openai.com）。禁止跟随重定向。保存不联网，也不尝试收费连接测试。启用生成时需创作者明确授权、原子预算预留和最大输出上限。每条任务冻结工作区配置修订/模型/价格摘要；修改后旧任务明确阻断，不采用新配置悄悄重放。

Key 仅存在加密字段和受控执行时的内存中，不进入 Prompt、任务快照、诊断或隐私导出；恢复备份必须同时保管主密钥，不能把它与业务 ZIP 一起导出。环境密钥保持服务端管理，工作区覆盖配置不会修改进程环境或其他工作区设置。

采用官方 [Fernet 高层接口](https://cryptography.io/en/latest/fernet/)，安装版本/许可证与 notice 哈希记入依赖台账。库能保护数据库密文，不代表对管理员、被攻陷主机或错误日志的完整防御。真实提供商、价格来源及商业条款仍由操作者配置与核实。
