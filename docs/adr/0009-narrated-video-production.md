# ADR 0009：把旁白接入真实视频制作

状态：0.14.0-dev 已实现；实际中文语音与 1080p 成片证据见 `docs/implementation/NARRATED_VIDEO_VALIDATION.md`。

Issue #29。原来的脚本 narration 没有进入音频时间线，单独配音接口只存未核实素材，用户无法从内容直接获得带声音的成片。本机已读到 Microsoft Huihui Desktop / zh-CN，不新增云服务或模型费用。

增加持久化 NarrationJob（DB 0014）：冻结工程、品牌/素材依据、逐镜头文本、真实声音、语速、时长政策和用户本次使用确认；Worker 独立合成、测量音频、对齐时间线、保存音轨和字幕，排队真实预览。自动适配时长须由用户选择；固定时长遇到超长配音明确失败，不能截断旁白。单一合成音轨容纳最多十二镜，已有旁白替换、配乐保留并校验范围；不默默覆盖用户字幕。

制作请求幂等并使用租约；本地安全步骤可恢复，不调用语言模型。完成前再次锁定和验证版本、事实/素材，不覆盖中途编辑。音频使用确认来自本次操作者，不能冒充系统对商业许可的认证。预览到高清仍需人工核对，最终发布由用户本人完成。

指定内容入口支持直接带配音制作，旧工程增加同一制作面板；进度、错误、试听、预览、高清下载可见。旧接口/无配音流程兼容。新增 narration_pipeline@1，IR 1.1 增加兼容的末帧停留字段，引擎冻结为 pillow_ffmpeg@3。迁移仅加表；回退前保全新库与文件，恢复对应备份，不删表降级。

最终实现新增兼容 Shot.freeze_end_frames，渲染器冻结为 pillow_ffmpeg@3，IR 仍为 1.1。连续制作验收发现旧质量确认把其他作品的比较历史也当成撤销依据，已修正：其他作品变化不撤销当前片，当前作品/事实/素材和预览字节仍严格绑定。详情与失败 trace 见验收文档。
