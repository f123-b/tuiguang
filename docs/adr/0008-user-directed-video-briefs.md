# ADR 0008：用户指定内容与可编辑视频脚本

状态：已实现并完成本地真实验收，0.13.0-dev / DB 0013。结果见 `docs/implementation/USER_DIRECTED_CREATION_VALIDATION.md`；GitHub 校验按该文档追加实际结果。

对应 Issue #27。新增独立“指定内容创作”，不替换日更创作者：保存带版本的主题、内容要求、受众、逐镜头原文、必现文字、禁用词、行动引导、时长、比例、制作形式、核实事实及授权素材。

先保存需求，再选择原文模式或单独授权模型写脚本。原文模式保留每行文字，不调用模型；模型模式冻结需求、品牌事实与素材元数据，按配置报价预留共享创作者预算，未知回执不重发。用户指令不是品牌事实；模型只能引用所选已核实事实，输出仅是待确认建议。脚本及其人工修订分别保存，修改需求/依据后旧脚本不能建立新工程。

用户可编辑分镜时长、画面文案、旁白文字、画面说明与素材；确认脚本后建立独立 VideoProjectIR，并生成带水印预览。画面说明是制作建议，不虚构已生成的画面；旁白是文字脚本，需在视频工作室另行添加授权音频。当前可运行 MG、真实图片/录屏合成，未接入扩散式视频模型。预览后沿用 #25 的人工确认/高清规则，不自动发布。原文模式没有创作者也可使用；付费写脚本需管理员、同品牌创作者处于运行状态、模型授权及本次预算上限。

DB 0013 新增 creation_briefs / brief_plans；BriefPlan 绑定一次模型任务、不可变脚本和可选建立的工程。保存需求采用乐观锁，建立工程加写锁并幂等，脚本不作为已核实事实。原有数据、日更 Prompt、模型配置和视频引擎不变；新增独立 directed_video@1 Prompt/任务版本。私有导出包含需求和脚本，公开诊断只记录 ID/版本/哈希。回退保全当前库、工作区文件与主密钥，再恢复对应旧库和提交，不删历史降级。
