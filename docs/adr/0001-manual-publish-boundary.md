# ADR-0001 第三方平台发布边界
状态：Accepted（产品约束，2026-11-05）

## 决策
持续 AI 创作者可自动策划、生产、审核、准备发布包、记录用户自行报告的结果，**但不在用户的第三方社交平台账号上完成最终发布**。

## 原因
平台接口和自动化规则随时间变化，商业化账号安全风险难以由第三方工具可靠消除；用户明确要求由本人在官方界面执行最后操作。

## 约束
- 不提供自动点击上传/提交的浏览器功能，不收集平台登录密码/Cookie/验证码。
- 发布状态 `user_reported_published` 与 `verified_by_platform` 不能混淆，当前产品不提供后者。
- 运营数据由用户手工导入或经明确合法授权的一方来源获得。
- 人工操作不保证免于内容审核/账号处罚，内容事实、素材授权、AI 标识和平台规范仍要合规。

## 回归测试
创建/导出/下载/手动登记的端到端测试不得访问第三方社媒写接口。模型/工具注册表无社媒发布工具；依赖升级时复核网络访问权限。
