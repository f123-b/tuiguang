# ADR 0006：授权产品来源、快照与素材适用版本

个人本地使用，来源由用户主动指定并授权：公开 GitHub Release、公开 HTTPS 文档、用户上传 TXT/MD 版本说明。没有私有仓库凭据或未经授权扫描。

网络只允许公网 HTTPS/443，禁止账号/查询/片段、内网 IP、重定向。解析 DNS 后只向已验证的公网 IP 建连接，同时保留原域名 TLS 证书验证与 Host，避免二次 DNS 解析；响应按流限制 512 KiB，拒绝非文本/JSON类型与压缩。来源资料始终是不可信数据，不执行其中指令。

Worker 租约抢占后释放数据库锁再抓取；提交前复查授权/启用状态和配置版本。首次建立基线，内容变更保存不可变快照、diff 与待审核事件。用户摘录变更才创建品牌提案，仍需明确“已上线”及人工确认才能成为已核实事实。

素材可绑定来源与适用版本。来源变化只判定“待复核”，不宣称旧画面必然错误；撤回该素材 verified 并使引用它的未登记稿重新审核，已登记历史不改写。重新核实适用版本后仍需单独核实使用权。未绑定旧素材保持原行为。

0011 为扩展式新表/可空字段与状态默认值；不新增外部模型费用。停用不再抓取，失败保留上次成功快照，不以空内容覆盖。回退停进程并恢复已验证备份，不删表降级。
