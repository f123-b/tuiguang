# M2-003 / GitHub #5：可编辑图文卡与真实导出

目标：将现有 CSS 封面示意升级为真实多页图文工程，预览与发布包使用同一渲染文件。主模块 GRAPHICS，依赖 PR #4（当前基线 20f8694），本轮独立增量 PR，不合并旧 PR，不部署生产。

范围：1–6 页，产品笔记/事实清单/授权截图三种版式，竖版 1080×1440、方形 1080×1080、横版 1920×1080，三种主题；保存工程、页序调整、精确图片预览、人工复核后下载 PNG/JPG、工程 JSON、发布包包含全部图文。用户文字同正文接受风险预审，事实卡仅引用有效事实，截图只用同工作区/同品牌已核实图片，不虚构产品界面。

调用链：编辑图文 IR → 乐观锁保存（内容 revision 递增，取消审核/旧包失效）→ 权限/事实/素材/文本长度检查 → 本地 Pillow 渲染真实 PNG/JPG/哈希回执 → 待人工审核 → 既有手动发布 ZIP；无第三方发布请求。未保存改动不得用于审核或导出。

影响文件：`graphics.py`/`graphics_api.py`、Content 两个可空 JSON 字段、迁移 0003、`domains.py` 的预审/打包、内容路由的锁与失效传播、Web 图文编辑器/模板入口、实际 OpenAPI/错误目录、回归/升级/浏览器验收与使用手册。旧内容 graphics=NULL 继续原封面流程；旧历史包不改写。

验收：先失败的 API/真实产物测试；三版式三尺寸；文本不能静默裁断；截图完整适配；重复渲染哈希可复用；旧页面 409；未审核下载阻断；图文绝对化宣称和过期/跨租户素材阻断；保存后旧包失效、已自报内容不改写；完整 ZIP 含真实 PNG/JPG/工程/来源；0001→0003 保留旧内容/账本；既有视频/选题/手动发布回归；桌面/移动真实浏览器和 CI SQLite/PostgreSQL。

版本：应用 0.3.0-dev、DB 0003、graphic_schema_version=1.0、graphic_renderer_version=graphic_cards@1；Agent graph@2 / fact_bound@2 / local_editorial@2、Video IR 1.0 / pillow_ffmpeg@1 不变。使用现有 Pillow，无新增运行时依赖/付费服务。字体记录实际指纹，商业发行仍按 LICENSE_INVENTORY 核实字体与 FFmpeg 边界。

风险/回滚：渲染为本地 CPU，限制六页和固定像素；错误保留草稿，不输出假成品。扩展结构不执行危险 downgrade，保留私有 `.data` 与升级前备份。旧版本不理解新图文，回退前暂停新任务，避免旧打包器忽略用户图文。未纳入自由画布、任意坐标、平台当前规则保证、TTS/视频多轨、AI 周报或商业生产部署。
