# F / #17：真实模型复盘的预算闭环

在默认免费规则报告之外，用户可单独授权将选定窗口的统计摘要、反馈标签与作品标题发送给已配置模型。保存独立 learning_review 任务，和日更共用原子预算/未知费用保护，不能被日历误认为日更。模型解释、可能相近主题与策略建议需人工复核；确定性统计不由模型覆盖。

任务冻结输入摘要、内容版本、模型配置修订与费用参数；不把密钥、原始正文或反馈原文写入输入摘要。提供者超时或格式不明不重试，保留预留；管理员可提交有来源的人工费用核对，标明 user_reported，既不代查账也不重发旧请求。

扩展迁移 0009：指标可空用户自报内容版本、AI 报告到任务的唯一关联、费用核对 JSON。旧指标版本保持未知；CSV/XLSX 缺省字段不改变旧指纹。现有规则报告、日更、媒体、人工发布不缩水。外部提供者实测仍需要用户凭据与授权，本轮仅受控提供者验证，不冒充真实调用。

验收：先失败；独立隐私授权/预算/暂停、同资料幂等、配置变更、未知结果不重试、核对可解除后续任务阻断、日历与日更隔离、原数字不被模型改写、来源 ID 和内容版本校验、跨工作区与密钥不泄露。最后统一浏览器、媒体黄金片和远端 CI 验收。
