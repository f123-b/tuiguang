# M1-002 / GitHub #3：可编辑计划驱动持续创作

产品目标：让 14 日计划成为真实持久化的创作依据，用户的改题、锁定、改期、跳过和批量确认均影响 Worker。前置为 PR #2 / 0.1.0-dev，本轮使用独立增量 PR。

观察：旧 `/calendar` 仅在 GET 时计算标题；后台按日期重新挑模板，不读取用户计划。目标：计划可追溯、可审核，执行时冻结选题版本，并保持旧任务可恢复。

影响：CREATOR / AGENT / WEB-PAGES。新增 `editorial_entries`，运行输入快照与可空计划关联，预算账本增加实际计费日；迁移 `0002` 为扩展式。本地开发库可升级，生产迁移不在授权范围内。API 版本保留 v1，Agent 图增加 v2 并兼容 v1，规则模板变为 v2，视频 IR / 引擎不变。

调用链：计划创建 / 编辑 / 确认 → 日程或用户确认提前准备 → 唯一日任务 + 冻结快照 → 事实时效 / 暂停 / 当日预算门 → LangGraph → 待人工审核内容 → 现有人工发布包。

验收：持久化与重启、乐观锁/并发、跨租户拒绝、改题后重新确认、锁定不被刷新覆盖、跳过不执行、改期交换不丢选题、时区/DST、七种角度草稿及真实导出、批量确认与预算、事实变更阻断、v1 任务兼容、0001→0002 保留已有数据。功能测试先失败再实现。

风险：批量提前准备可能集中消耗当天模型预算，必须明示确认并检查真实执行日；未知付费回执保留预留，不重发。自动新增的规则选题依照用户已经开启的创作者配置执行；手动改题后需要重新确认。离线规则草稿继续明确标记，真实模型凭据联调不能假称完成。

权限/成本：仅所属工作区，计划操作本身不调用模型；不新增依赖与收费服务。沿用既有人工发布、独立 IR、观测 ADR，无生产高风险架构变更。

未纳入本 Issue：语义向量检索、AI 周报与长期偏好学习、自由画布、TTS/GPU/云存储。完成后更新实际状态，不将本次能力等同全部 M1–M7。
