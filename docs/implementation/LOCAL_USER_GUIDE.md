# 0.1.0-dev 实际使用步骤

这份手册描述当前实际功能；`docs/03` 是完整产品目标手册。

1. 按根 README 启动，访问 `http://localhost:3000`，注册自己的工作区。没有默认账号或预置运营数据。
2. 品牌与素材：输入真实产品、受众；每条事实用 `功能 | 来源` 一行填写。勾选用户已核实后保存。未核实的事实不会进入创作。
3. 素材库：主动上传截图/录屏，填写来源、授权说明和用户确认。只能将自己有权使用的素材交给本软件。
4. 我的创作者：设定名称、风格、平台内容规格、时区、小时、每周频率和整数分预算。保存会开启创作。当前默认规则草稿明确标注，无收费模型调用。
5. 准备今日内容：后台处理日任务；页面对排队任务定期读取状态。当天重复点击只返回同一任务。查看运行日志可找到任务 ID 与错误。
6. 内容工作室：编辑标题/正文，保存后重新审核。检查事实与预审风险，人工确认后准备发布包。修改品牌资料也会让待发布内容重新审核。
7. 视频：创建 MG、真实素材或混合项目，逐镜头改参数；渲染由后台实际执行，完成后可播放并下载 MP4 / 工程。修改镜头后旧片不再充当新版，重渲染会复用未改镜头。
8. 人工发布中心：下载 ZIP（封面、文案、来源、检查表），复制文案。用户本人在官方平台上传与发布，本软件不操作站外账号。发布后勾选五项清单、填写实际时间和可选链接，再登记；结果标记为用户自报。可撤销本软件中的登记。
9. 数据导入：下载固定 CSV 模板；从页面展开当前内容 ID。填入平台、指标、开始/结束日期、带时区的观察时间。缺失指标留空。上传 CSV / XLSX 并写明来源，先预览再确认。
10. 成长页当前汇总软件内真实记录，不生成 AI 因果结论、周报或策略学习。那些能力显示为待接入。

暂停会阻止新生成任务；已经发起的模型请求或本地渲染不会被伪装为撤回。未知模型费用保留预留，并阻止自动重试。遇到错误保留诊断编号，不要提供账号密码、Cookie 或 API Key。

软件内置 `/help` 提供同一实际流程说明。所有验收截图中的“验收测试”工作区和合成指标只用于测试，并未在第三方平台实际发布。
