# 0.14.0-dev 实际使用步骤

这份手册描述当前实际功能；`docs/03` 是完整产品目标手册。

1. 按根 README 启动，访问 `http://localhost:3000`，注册自己的工作区。没有默认账号或预置运营数据。
2. 品牌与素材：输入真实产品、受众；每条事实用 `功能 | 来源` 一行填写。勾选用户已核实后保存。未核实的事实不会进入创作。
3. 素材库：主动上传截图/录屏，填写来源、授权说明和用户确认。只能将自己有权使用的素材交给本软件。
4. 我的创作者：设定名称、风格、平台内容规格、时区、小时、每周频率和整数分预算。保存会开启创作。当前默认规则草稿明确标注，无收费模型调用。
5. 选题与日历：保存创作者会按频率建立未来 14 天计划，旧工作区可点击“补齐 14 天计划”。规则选题按已经开启的配置自动确认；查看选题可改标题、角度、所引用的已核实事实及锁定。保存修改后勾选核对并“确认这个选题”，才会按时执行。未保存的修改不能用于确认或提前准备。交换日期会移动两条选题，两条都需要重新确认；跳过后当天不自动创作。
6. 提前备稿：在日历选择最多 7 条已确认选题，核对日期和预算，勾选同意后开始。费用按实际执行日累计，预算不足会暂停；当前默认本地规则草稿无模型费用。当天重复提交只返回已有任务，未知付费结果不重发。创作者页展示下一次可执行时间；暂停时不会执行。品牌事实变化会阻止旧计划，未执行计划可重新选事实并确认；已冻结的任务须保留原依据，请在尚未执行的日期安排新稿。
7. 内容工作室：编辑标题/正文，保存后重新审核。检查事实与预审风险，人工确认后准备发布包。修改品牌资料也会让待发布内容重新审核。
8. 封面与图文卡：从内容详情进入编辑器，选择 1–6 页和版式、尺寸、配色。事实清单引用当前内容事实，截图需选择已核实授权图片。先保存图文工程，再生成真实预览；逐页查看服务端图片，复核全部图文后确认审核。修改会取消审核、使旧发布包失效；文字放不下时会报错，不截断替代。审核后可下载本页 PNG/JPG，或准备包含全部页、工程和来源的发布 ZIP。工程 JSON 是编辑数据，不代表审核通过。
9. 视频：创建 MG、真实素材或混合项目，逐镜头改参数；渲染由后台实际执行，完成后可播放并下载 MP4 / 工程。修改镜头后旧片不再充当新版，重渲染会复用未改镜头。
10. 人工发布中心：下载 ZIP（封面、文案、来源、检查表），复制文案。用户本人在官方平台上传与发布，本软件不操作站外账号。发布后勾选五项清单、填写实际时间和可选链接，再登记；结果标记为用户自报。可撤销本软件中的登记。
11. 数据导入：下载 CSV 模板或读取 CSV/XLSX 列名进行字段匹配；从页面展开当前内容 ID。填入平台、指标、时间窗、带时区的观察时间和可选作品版本，未知留空。上传并写明来源，先预览再确认；也可手工填写，有误批次可撤销。
12. 成长页可提交主动反馈、整理有证据的规则周报、审批/拒绝/回滚偏好策略，后续计划冻结已批准偏好。模型解释与相近主题建议需单独授权并计入预算；缺数据仍显示证据不足，不生成平台因果结论。

暂停会阻止新生成任务；已经发起的模型请求或本地渲染不会被伪装为撤回。未知模型费用保留预留，并阻止自动重试。遇到错误保留诊断编号，不要提供账号密码、Cookie 或 API Key。

软件内置 `/help` 提供同一实际流程说明。所有验收截图中的“验收测试”工作区和合成指标只用于测试，并未在第三方平台实际发布。

品牌页面的“版本变更待核实区”只保存提案；确认已上线并核实后才批准为事实。在素材库可停用过期素材。内容详情展开“修订历史与平台文案”，比较旧稿、确认恢复为新版本或保存分平台副本；修改原因用于后续复盘。历史快照是私有证据，不进入公共诊断日志。

视频编辑器可增删排序镜头、修改入点和速度、选择三种比例，保存整个工程后再渲染。锁定镜头需要主动解锁才可改内容；版本恢复需确认并生成新版本。上传授权音频后添加旁白或配乐，设置帧位置、源入点、音量；只有音乐允许循环。字幕填写起止帧和文本，导出 MP4 会烧录，也可单独下载 SRT。Windows 本机语音可离线合成，生成资产仍须核实使用权。到内容详情绑定已完成的成片，观看并核对音画后重新审核，发布包会包含 MP4/工程/字幕。旧 1.0 工程可读取，点击“升级并保存工程”后用新版渲染；旧片与旧 ZIP 不改写。

数据导入可先“读取列名”，逐项匹配文件列，再校验预览与确认。展开“手工指标与导入纠正”填写观察值；留空表示未知。有误批次可停用后重新登记。成长页选择日期生成证据周报，查看分组统计和原始依据；反馈及修改原因可形成待审批偏好，确认后才影响新计划。策略可拒绝或回滚，撤销其来源也会停用相关偏好；旧报告和作品不改写。默认周报由本地规则整理；真实提供者联调范围见 CREATIVE_QUALITY_VALIDATION.md 与 USER_DIRECTED_CREATION_VALIDATION.md，不将受控测试当成真实运营效果。

通知中心可查看审核/失败/预算/复盘待办、标为已读和设置手动发布提醒。设置页选择及时通知、每日一次或关闭；提醒只保存在本软件。发布中心可保存暂缓/用户报告平台拒绝/放弃等自报结果，不能代替真实发布登记。设置中的模型密钥加密保存，地址须经操作者允许；保存不调用模型，启用生成还要在创作者中授权并设预算。修改配置后未执行旧任务会阻断，未知付费请求不重试。私有导出不含密码、会话或密钥；原始素材随导出时仍需自行核实授权。费用按整数分账本展示，不是正式供应商发票。

创作者设置展开“日任务同时制作图文与视频”，主动选择图文卡、视频形式、尺寸/时长及授权素材后保存。默认旧配置不启用。每个新任务冻结这些选项；媒体仍等待人工审核，默认本地视频没有配音。暂停会阻止新自动媒体步骤，已开始的工作可完成；素材失效或源稿修改会明确阻断，不能静默换成其他风格。媒体失败时，草稿和已知费用保留，可去工作室处理；不会为补媒体再次请求模型。


## 模型复盘和未知费用

默认周报是免费本地规则统计。设置页保存允许的 HTTPS 地址、密钥与有来源的价格；创作者仍需模型授权和预算。成长页选择日期并单独同意发送标题、统计摘要和反馈标签，才可发起模型复盘。后台完成后在报告历史切换，解释和相近主题都需复核，策略需另外批准。超时或回执格式不明会暂停；先自行查提供者账单，在设置页记录核对来源和整数分，再手动恢复创作者，旧请求不会重发。手工或导入指标可填写作品版本；不清楚时留空。


## 独立模型设置与联调

设置 → 打开模型设置（`/settings/models`）。填写兼容接口 Base URL 和密钥，确认信任地址；可先保持规则模式保存，然后勾选允许读取模型列表。选择或手填模型名称、实际价格来源及参数后启用模型。换网关须重新输入密钥，保存不会联网。实际生成联调需创作者正在运行且已授权，勾选本次测试并确认整数分上限；测试只发送固定 JSON，不发送品牌资料。回执绑定配置版本；401/403/限流/不支持列表有独立提示，未知生成回执停重试并保留费用预留。


## 产品动态与素材版本

品牌页“产品动态监测”添加你有权使用的公开 Release/文档或上传说明来源。确认授权后按间隔检查；首次只建基线，变化记录差异，失败保留旧快照。查看快照再摘录为待核实功能提案，仍须在变更区核实已上线。网页导航等变化也可能触发差异，应人工辨别。上传只接收 UTF-8 TXT/MD。

素材页“素材适用产品版本”关联来源，核实当前版本。关联来源变化后，该素材和未登记稿会待复核；先确认素材适用的新版本，再单独重新核实使用权。没有关联来源的旧素材保持原行为，已登记发布包不改写。来源停用后不再检查；不支持私有仓库凭据采集。


## 创作质量与预览确认

内容和视频编辑器都有“创作质量与人工判断”。草稿生成会保存规则报告；编辑后点击“检查当前作品”检查最新版本。展开检查依据查看引用、广告词、近 30 条标题和近 10 条视频镜头结构，字面相似不能证明语义重复。受众价值、单一收益点、开场吸引力和行动目的仍须人工判断。

需要语义建议时，单独展开模型复核，确认发送当前文案（含图文卡及分平台文案）、已核实事实、受众及最近标题，选择同品牌创作者和本次费用上限。建议单独保存，不会替你修改草稿或批准审核。账本按你配置的单价和用量估算，整数分向上取整；实际扣费请核对服务商账单。请求未知时不会自动重发。

新界面创建的视频工程先“生成低清预览”，播放带“内部预览”水印的实际视频，核对字幕、声音、事实、受众和一个主要收益点；填写复核记录并确认后，“生成高清成片”才可提交。预览不能作为视频附件或进入发布包。工程、品牌依据或素材变化后需要重新检查、确认；历史相似度保留为审核时比较，制作其他作品不会让未改动的成片失效。硬性事实/素材问题不能强行通过。旧工程保留原渲染流程，也可主动预览。创作者设置可勾选“先生成低清预览”，自动制作会停在待确认，去视频工作室完成上述步骤。

DeepSeek 官方接口已实际联调：Base URL `https://api.deepseek.com`，模型 `deepseek-flash`。此官方模型的 JSON 工作流自动使用非思考参数；其他兼容网关保持原参数。配置已保存在本机，刷新模型设置可见，密钥输入框始终留空，空白不代表未保存。

## 你来规定视频主题和内容

侧栏进入“指定内容创作”（`/studio/briefs/new`）。没有产品资料时，可先在此填写产品/项目名称、介绍及受众，保存后直接创作，不会开启自动日程。DeepSeek 写脚本和旁白文字，本机系统声音将其合成为真实配音，再与动态文字、真实录屏/图片合成视频。人物表演或任意新场景需要另接视频模型，画面说明不会自动变成相应动画。

1. 填主题、内容和结构要求、受众及语气。填写必须原样出现的文字、禁用词、结尾引导；选择 3–60 秒、横/竖/方形与 MG/实录/混合形式。勾选本次允许引用的核实事实及授权图片/视频，保存要求。未核实的新产品声明先去品牌页核实，需求本身不作为事实。
2. 想严格按自己的文案：原文框每个非空行作为一镜，1–12 行、每行最多 180 字，点击“按原文准备分镜”。会均分时长，无模型费用，也不要求创作者运行。
3. 想让 AI 按要求写：启用模型配置，同品牌创作者须运行且有授权和预算；勾选本次发送资料同意，填写费用上限再提交。请求与日更共享预算，完成后查看脚本；未知回执不重发。没有素材时只选 MG。当前 AI 品牌脚本至少需要一条已核实事实。
4. 检查标题、引用事实、每镜画面文字、旁白文字、画面说明、时长和素材，增删排序后保存脚本修订。原始稿与历史保留；不满足必现文字、结尾、禁用词或总时长的稿件会提示修改。修改创作要求或依据后，旧脚本不能建立新工程，需要重新准备。
5. 在分镜下方保留“制作配音、同步字幕和视频”，选择本机中文声音、语速和时长政策，确认本次使用权及脚本，点击“制作带配音的视频预览”。逐镜头生成声音、加入音轨和同步字幕后，后台自动合成带水印预览；可查看进度、试听或下载配音。选择自动延长时总时长可能增加，录屏在原镜头结束后停留末帧；固定时长容不下旁白会提示修改，声音不会被截断。锁定的镜头需先解锁才能延长。
6. 在视频工作室播放预览，核对完整旁白、事实、字幕和画面；填写复核记录并确认，再点“生成高清成片”。后台完成后可直接播放、下载 MP4，字幕可导出 SRT。要加入发布包，仍需在内容详情绑定成片并重新审核，用户自行在平台发布。

本次真实 AI 脚本、原文修订、6 秒预览/高清及下载哈希证据见 [指定内容创作验收](USER_DIRECTED_CREATION_VALIDATION.md)。测试数据在独立合成工作区，不会代替你的品牌资料。私有记录导出包含需求和脚本，仍不包含模型密钥。

## 已有视频如何完成配音制作

打开视频项目，顶部“配音与视频制作”会读取原脚本的旁白；没有原脚本时预填镜头文案。填写每镜旁白，选择声音和时长政策，确认本次本地使用权后提交。一个任务最多 12 镜、4000 字、合成后 120 秒；已有旁白会替换，配乐保留。已有字幕时取消自动字幕，保留并随延长后的镜头重排；若要完全重新生成字幕，先在工程中删除原字幕并保存。

后台制作期间可查看进度；失败会显示具体镜头、超长/锁定/语音/依据问题，修正后重新提交。制作期间编辑了工程或撤销了素材，旧任务不会覆盖新版本。配音完成后产生新工程版本，旧高清审核不能继续沿用，需重新播放预览并确认。手动配音不受自动创作者暂停状态阻挡，也不会恢复自动日程或调用 DeepSeek。

本机有中文语音时使用 Windows SAPI 离线合成，无额外模型费用。没有声音可选时先安装系统中文语音或上传自己的配音。原“单独生成音频素材”保留在高级选项中，只生成素材、不自动加入成片；完整制作请使用顶部入口。用户本次使用确认不等于软件对商业使用许可作出认证。真实有声成片和测试记录见 [完整流程验收](NARRATED_VIDEO_VALIDATION.md)。

高清完成后可点击“下载成片”。如果浏览器取消自动下载，点击旁边“保存到本机文件夹”，软件会直接将 MP4、配音、SRT 和工程 JSON 保存到本工作区 exports 目录，并显示文件绝对位置。复制该位置到资源管理器即可打开；此功能仅用于本地使用，不提供任意服务器目录写入。


## 软件产品发布片

在“AI 宣传视频”新建工程，默认选择“软件产品发布片”。写开场、补充说明、真实功能要点和结尾，选清晰的真实截图或录屏。新工程安排开场、功能、全景、特写、收尾；没有素材时仅使用文字版式。指定内容创作也可在首次建立视频前选择发布片风格。

工程顶部可改主题、强调色、品牌署名和镜头衔接；每镜的“发布片分镜设计”可改主标题、说明、编号要点、百分比裁切及推进/平移/静止。特写默认中部裁切，请播放检查是否看到了需要的操作；原始录屏分辨率不足时，放大不会补出真实细节。文字溢出会提示缩短或拆分。已有工程需主动切换风格，保存后重新生成预览和审核。

声音整理可统一响度并在旁白时压低授权配乐，不能改善系统声音的音色。更自然的声音可上传自己的授权配音；本轮没有云配音或自动音乐库。详见 [真实样片和验收](SOFTWARE_FILM_VALIDATION.md)。
