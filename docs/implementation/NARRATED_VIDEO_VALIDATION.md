制作任务冻结原工程和依据，采用数据库幂等键及租约，进度和错误可见；完成配音后自动保存新修订、音频、字幕、规则报告和预览任务。最终高清仍需播放预览并确认，第三方平台仍为人工发布。语音来自本机，没有新增网络服务、依赖、模型费用或 Prompt 版本修改。

另复核到实际“有招”工作区没有产品或创作者，原入口只能跳转资料页。新增入口内最小产品表单，仅保存用户自行填写的名称/介绍/受众，不自动添加事实或开启创作者；在新建合成空工作区中实际填写并成功进入创作表单，375px 截图保留。
