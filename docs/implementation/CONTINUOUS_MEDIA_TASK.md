# E / M1-M3-008 / #15：持续创作者的媒体制作连接

目标：已实现的日任务、图文与视频不再是孤岛；用户明确配置后，日任务保存真实草稿并制作可审核媒体。原创作者 render_options=NULL 保持原行为，不替用户开启制作或修改预算。

调用链：创作者保存可选制作规格与授权素材 → enqueue 冻结规格/来源哈希 → 规则/授权模型生成草稿 → 真实内容与费用先结算 → 低成本图文渲染或独立视频任务 → 文件/媒体质量验证 → 人工复核 → 原人工发布包。媒体失败保留草稿和已知费用，不再次请求模型。自动视频入队、恢复和完成都核对源内容/品牌/素材及暂停状态。

影响：CREATOR/AGENT 周边任务生命周期、VIDEO/GRAPHICS 接口边界、Creator 一个可空 JSON 字段的扩展迁移 0008、配置 UI 和实际契约；不修改第三方发布边界。固定版式与本地 CPU 模式，没有生成式云视频、外部语音收费请求或生产服务开通。

验收：先失败测试；旧配置兼容；冻结选项；自动图文真实 PNG/视频真实 MP4；暂停阻止排队自动渲染；失败/恢复不重复模型/费用；修改来源阻断旧媒体；14 天受控时钟；30 秒三种黄金片；浏览器桌面/移动与最终 SQLite/PostgreSQL CI。尚未执行的项目必须明确记录，合成测试不是 M7 实际用户试点。

回滚保留扩展列，暂停新版自动制作，旧已完成内容/发布包不可改写；完整恢复从升级前备份到隔离环境，不进行删列 downgrade。
