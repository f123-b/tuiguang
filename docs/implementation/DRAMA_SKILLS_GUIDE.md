# 短剧制作与内置 Skills

本地入口：http://localhost:3000/studio/video/drama 。视频类型中的“AI 动态场景生成”进入此页，旧 `/studio/video/ai` 保留逐镜生成、检查、取消和未知回执核对。

1. 保存原创/已获改编授权的故事、主题、题材、真人/动漫、10–60秒与横竖画幅。产品能力只选择品牌页已核实事实。
2. 选择同品牌创作者。模型设置可用、创作者运行中且已授权后，确认发送本次故事、设置费用上限，点击“用 Skills 规划短剧”。规划使用现有工作区兼容接口（含 DeepSeek）和预算。模型返回不代表可制作；格式错误或未知回执不会自动重试。也可手工填写计划，不请求模型。
3. 在人物/场景/剧本/镜头页修改目标、弱点、外观锁、光照、轴线、前因、障碍、行动后果、景别、运镜、站位和准确画外音。每拍一镜，最多12镜。保存后执行上游剧本检查及应用的编号、因果引用、覆盖、时长、站位检查。检查引用完整不能证明因果语义精彩；同一模型生成的规划不是独立导演审查。
4. 查看具体位置的阻断项及待核对条件。确认故事与分镜需写核对意见。修改计划/恢复历史会生成新修订，清除当前确认和绑定；已生成旧片段仍在镜头页和历史记录中，不会删除或重复提交。
5. 在素材库准备各镜对应的首帧，核实授权与当前版本；选择同一人物、服装、场景和构图。横屏原图至少1280×704、竖屏至少704×1280，比例须匹配。分辨率门槛不证明清晰或无畸形，仍要检查细节。`character-refs`提供锚点方法，**软件尚不自动调用其生图命令**，不要求开通外部账号。
6. 检查页逐镜“查看本镜生成参数”，审看完整提示词、参考、尺寸、时长后确认单镜。本机 Wan 2.2 无外部视频费用，但GPU占用较长；本机5秒实测约28分钟（只作这台机器的既往证据）。不会自动提交整片。重复同计划同镜请求复用任务；已完成/确定失败/取消后可勾选“重新拍摄本镜头”，保留旧片段并只替换本镜绑定。运行或未知状态不能重拍重复提交。
7. 动态镜头页检查角色、手指、脸、背景、动作、源清晰度和连续性；写意见确认片段。未确认、未完成、来源失效或低于计划源尺寸，短剧不能制作预览。
8. 所有镜头齐备后选择本机声音，确认声音使用权，按固定时长制作旁白、字幕和预览。留空的台词保持静默，不读“AI剧情演绎”标签。真实软件界面需后续在视频编辑器插入授权录屏。技术流程支持不等于表演/剧情/商用审查通过；高清仍沿用预览→质量报告→人工确认。

目前是一个选定的画外音声音；人物声音方向与每镜表演提示保存在计划中，未自动逐角色选声或逐镜施加自由语气提示。没有人物对口型、跨镜头身份保证、自动导演出图或一次完成长篇连续剧。需求可按集新建项目；不伪称已有分集生产管理。最终外部平台发布始终由用户手动完成。
