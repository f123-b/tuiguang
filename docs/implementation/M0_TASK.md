# M0-001：建立第一个真实本地创作闭环

目标：将仅有设计的空仓库变成可启动、可测试的 Web/API/Worker 工程。依据总指令“第一轮直接执行”和 V2.2“尚无后端则先做 P0 最小契约与测试 PoC”。

状态审计：GitHub 空仓库；本地仅设计包。无生产库、既有用户数据或模型凭据。

| 领域 | 实施范围 | 验收 |
|---|---|---|
| 品牌/权限 | 工作区注册登录、事实来源、用户确认、上传授权素材 | 跨租户资源不可读写 |
| 创作者 | 时区/频率/预算、持久日任务、暂停恢复 | 7 天受控时钟、并发幂等、重启恢复 |
| 内容/Agent | LangGraph 事实约束流程；本地规则草稿；可选真实模型网关 | 无模型不宣称 AI；未知费用不重试 |
| 视频 | 独立 IR、Pillow MG、FFmpeg 素材镜头、缓存、1080p 合成 | 真实 20–30 秒 MP4 和局部修改 |
| 交接 | 预审、人工审核、ZIP、用户自报登记 | 未通过不能打包；零平台写请求 |
| 数据 | CSV/XLSX 预览、确认、幂等、缺失值、来源与窗口 | 失败不部分入库；缺失不补零 |
| 工程 | Trace、错误码、版本、迁移、CI、文档 | 实际命令与限制记录 |

调用链：Web → FastAPI → 租户域服务 → SQLAlchemy/持久 Job → LangGraph 或 Video Provider → 本地不可变文件 → 审核 → ZIP → 用户自报 → 指标。

API `/api/v1`；新数据库 migration `0001`，不涉及生产迁移。代码版本 `0.1.0-dev`，不冒用设计版本 2.3。默认本地零模型费用，CPU/电力成本未计费；用户预算为整数分。规则草稿与真实 AI 输出分别标来源。

沿用 ADR-0001/0002/0003 的人工交接、独立 IR 和追踪决策；本轮采用许可已核对的独立 Provider，不复制候选项目源码。生产部署、收费服务、GPU 模型、支付与真实用户试点不在本轮完成声明中。
